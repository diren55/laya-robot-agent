# Laya Robot Agent

## 项目介绍

这是一个已经能在已接入的机械臂仿真任务中运行、但还不完善的机器人 Agent 原型。目标是用 Laya 承担主要的语义判断工作，结合轻量规划组件，减少生成式大语言模型推理带来的时间开销。

当前流程是：

**视觉检测＋深度信息与几何处理 → 结构化场景信息 → 动态问题编译器 → Laya 批量语义判断 → 概率与场景信息聚合、规划 → 机械臂执行 → 新观察与反馈。**

首先，使用 GroundingDINO 视觉检测模型，结合 RGBD 深度信息和几何处理，得到物体、位置及空间关系等结构化场景信息。这里不是用图文大模型自由描述图像。

随后，动态问题编译器根据当前场景信息、原始任务指令和执行反馈，组织有助于后续规划的一组语义判断问题，例如目标对象、动作意图、禁止事项、条件与步骤依赖。当前编译器由规则和技能目录驱动，随输入变化实例化问题，还不是训练好的问题生成模型。

这些问题批量交给 Laya 判断。聚合层将输出的概率与当前场景信息、任务图和已有执行记录结合，确定下一步技能、执行顺序或恢复处理，再交给机械臂执行，并通过新的观察继续更新。这里的概率是语义判断的支持度，不是物理动作成功率。当前版本的运行时语义判断、规划和恢复不调用生成式大语言模型。

整体已经有可运行的基本雏形，但复杂语义、动态出题质量，以及聚合与跨步记忆仍需完善；目前不能把它当成已经成熟的通用机器人系统。

## 后续工作

1. **复杂语义：** 做好否定、条件、指令更正、引用与时序等情况，先测试并定位具体问题，再针对性改造。
2. **动态出题：** 计划训练动态问题生成模型，根据场景、任务和反馈生成质量更高、更有助于规划的问题，避免同质化问题和超出 Laya 能力范围的问法。
3. **聚合与跨步记忆：** 改进概率整合、任务依赖、执行反馈和历史状态的配合，不只考虑眼前一步，也不把过去的状态当成当前事实。
4. **视觉与组件协同：** 后续计划训练或适配视觉模型，提高场景信息的准确性和完整性，同时完善各组件的接口与配置机制，再推进真机验证。
