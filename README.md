# Laya Robot Agent — Frozen T4 Research Prototype

这是机械臂仿真研究原型的完整交付仓库。运行时高层语义判断、规划和恢复不调用生成式大语言模型；当前视觉使用 GroundingDINO、RGBD 和几何处理，动态出题由规则/目录驱动的编译器完成，Laya T4 返回语义判断概率，轻量任务图聚合器选择已有技能。

## 完整代码与权重在哪里？

- **本仓库文件树**：便于查看和版本管理的源代码、配置、依赖说明、许可证及结果摘要。
- **Releases → `v1.0.0-t4`**：完整原始交付 ZIP 的四个无损分卷，包括 T4、基础 Laya、DINO 权重，以及机器人/仿真资产。没有量化、裁剪或改变权重。
- **不要只下载 GitHub 自动生成的 Source code ZIP 就直接运行**：它不含大型权重和二进制资产。请下载 Release 中全部四个 `.zip.001`–`.zip.004` 文件。

每个分卷小于 1 GB，前三份各 950,000,000 字节，最后一份 380,258,612 字节。总大小 3,230,258,612 字节。

## 下载、合并与运行

1. 从 Release 下载四个分卷、`merge_parts.py` 和 `parts_manifest.json`，放在同一文件夹。
2. 使用 Python 3 执行 `python merge_parts.py`。脚本按顺序合并，并验证分卷与完整 ZIP 的 SHA-256；不会覆盖已有同名 ZIP。
3. 解压得到完整 `laya_agent_delivery_20260930` 目录。
4. 按目录内 `README_先读我.md` 安装依赖、运行仿真。需要 Linux GPU 环境；Windows 可以保存、传输、合并和解压，但不是 Windows 一键运行程序。

也可使用支持此类分卷的 7-Zip 打开 `.zip.001`。只验证而不合并：`python merge_parts.py --verify-only`。

若同时保留分卷、合并 ZIP 和解压目录，建议至少有 11 GB 空间。依赖安装需要网络；模型权重已在完整包中。新机器从零安装尚未验证，本版本在现有兼容环境完成了四类打包运行核查。

## 当前实现与边界

链路：当前 RGBD → DINO/几何场景证据 → 动态语义问题编译 → Laya T4 批量判断 → 约束任务图聚合与恢复 → 机械臂技能执行 → 新相机反馈。

- 已接入 CubeLift、CubeStack、CubeRestack、SpillWipe 四类原生任务。
- 动态出题器不是另一个训练好的生成模型；聚合器也不是生成式大模型。
- 概率表示语义判断支持度，不是物理动作成功率或安全保证。
- 采用 CaP-X 平台和公开组件的适配实现，不是完整原论文复现。
- 本包是冻结推理/仿真交付，不是从头训练复现包；不含全部历史实验原始数据。
- 不含生成式模型对照、生成式回退、API 密钥、登录凭据或聊天记录。

## 冻结版本结果：正反证据均保留

- 四类原生任务 × 8 固定初态：T4 32/32 完整成功，0 未知/程序错误。
- 同任务本地 Phi-4-mini 短缓存计划适配对照：14/32。14 个共同成功例的暖启动完整墙钟均值为 Laya 5.81060 秒、Phi 8.91681 秒，物理步一致。只代表该适配对照与这些开发场景。
- 简单规则对照：双方 32/32；规则约 5.18606 秒、Laya 5.47692 秒。因此这些固定表达不能证明 Laya 相对规则的必要性或速度优势。
- 旧丰富语义开发集为 27/28 动作、2/2 无动作、2/2 正确澄清；与原生 32 不是同一批数据。
- 独立 128 TEST 尚未运行；未证明开放世界泛化、统计非劣或真机安全。
- 新的复杂语义诊断和修复不属于这个冻结 Release；不要将新试验未完成的成绩混入此版本。
